Welcome to WebRTC Chat! Connect to start messaging.

How to use this WebRTC application:

  1. Open this page in two separate browser windows or tabs
  2. In both windows: Click "Start Camera" to enable your webcam and microphone
  3. In both windows: Click "Connect to Server" to connect to the WebSocket signaling server
  4. In either window: Click "Start Call" to initiate a video call with the other user
  5. The call will be automatically established via the WebSocket server
  6. Use the text chat to send messages during the call
  7. Click "End Call" to disconnect the video call (text chat remains active)

Note: This application uses a simulated WebSocket server for signaling. In production, you would need a real WebSocket server running on your backend.
