How to use this WebRTC application:

  1. User 1 (Server): Click "Start Camera" then "Start Call" to create an offer.
  2. Copy the offer data from the Connection Data box.
  3. User 2 (Client): Start camera, paste the offer data into the textarea, and click "Answer Call".
  4. Copy the answer data that appears and send it back to User 1.
  5. User 1: Paste the answer data into the textarea and click "Paste Answer".
  6. The connection will be established and video/audio will start streaming between both users.

Note: This example uses manual signaling (copy-paste) to simulate a signaling server. In a real app, this would be handled automatically via a WebSocket server.
